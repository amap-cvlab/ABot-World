research examples and should not be described as ABot-World-0.5 demonstrations.
The copyright holder has authorized these images for use on the project site.

- `onela-robotics.jpg`: OneLA, selected generated robotics rollout poster. [Source image](https://fantasy-amap.github.io/OneLA/assets/robotics.jpg); [project](https://fantasy-amap.github.io/OneLA/).
- `gad-static.jpg`: GAD, static-scene comparison poster showing input, ground truth, baseline methods and GAD. [Source image](https://fantasy-amap.github.io/GAD/assets/images/static-1-poster.jpg); [project](https://fantasy-amap.github.io/GAD/).
- `trifold-reconstruction.jpg`: TriFold, reconstruction scene 342 preview. [Source image](https://fantasy-amap.github.io/TriFold/assets/splats/thumb_recon_342.jpg); [project](https://fantasy-amap.github.io/TriFold/).
