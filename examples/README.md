# Interactive Examples

Choose a third-person scene, start the stream, then click a skill.

| Scene | Skill 1 | Skill 2 |
| --- | --- | --- |
| 红杉林径 · Redwood Trail | Shadow Gravity | Hammer Shockwave |
| 高山湖畔 · Alpine Lake | Fish in a Water Sphere | Floating Jellyfish |
| 乡间小路 · Country Road | Flock of Birds | Cloud Lift |
| 极光雪原 · Aurora Snowfield | Flame Jet | Autumn Leaf Gust |
| 沙海驼影 · Desert Camel | Lightning Web | Surging Water Ring |
| 暮城猎魔 · Dusk Monster Hunter | Pillar of Light | Ring of Fire |

Each skill supplies a local action prompt for four generation chunks.
The optional text cache can be regenerated with `python scripts/preencode_examples.py`.
